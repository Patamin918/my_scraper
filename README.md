# reddit-scraper

Personal Python script that scans Rising posts on Reddit subreddits 
relevant to Excel and freelance finance.

## What it does
- Filters posts by age, upvotes, and comment count
- Drafts comment suggestions via Claude API for manual review
- Logs all results to reddit_log.json
- No automated posting — all comments posted manually

## Stack
- Python 3.12
- PRAW (Reddit API)
- Anthropic Claude API

## Usage
Personal use only. Not a bot — I review and post every comment manually.
